# OIBSIP-Task-3

🏠 **House Price Prediction using Linear Regression**

A Machine Learning project that predicts house prices using Linear Regression based on features such as house quality, living area, location, garage capacity, and other property characteristics.

🎯 **Objectives**

Perform Exploratory Data Analysis (EDA)
Handle missing values
Encode categorical features using One-Hot Encoding
Analyze feature correlations with house prices
Build and train a Linear Regression model
Evaluate model using MSE, RMSE, and R² Score
Analyze actual vs predicted prices and residuals
Interpret model coefficients
Compare Linear Regression with Ridge Regression

🛠️ **Tech Stack**

Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook

📈 **Key Analysis**

House Price Distribution
Correlation Heatmap
Feature Selection
Actual vs Predicted Prices
Residual Analysis
Coefficient Analysis
Linear Regression vs Ridge Regression

💡 **Key Insights**

Overall house quality, living area, basement size, garage capacity, and location are important factors affecting house prices. The Linear Regression model was evaluated using MSE, RMSE, and R² Score, while coefficient analysis helped identify features with positive and negative impacts on predicted prices.

▶️ **How to Run the Project**

1. Clone the repository

```bash
cd House-Price-Prediction
```

3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Start Jupyter Notebook

```bash

```

Open: `House_Price_Prediction.ipynb`
